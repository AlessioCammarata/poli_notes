A regular expression (or **pattern**) is an expression that specifies a set of strings.
Expressions are useful to find if a **match** exists between objects
- Directories or file names, lines or fields of a file, strings or sub-strings, etc.

They are composed by:
**Literal** 
- Any character (or character sequence) used in the search of a match 
	- ind matches windows, indifferent, etc. 
**Metacharacter** 
- One or more characters having special meaning 
	* indicates 0 to ∞ preceding symbols, e.g., b* = {φ, b, bb, bbb, …} 
**Escape sequence**
- Allows using literally a metacharacter 
	- Character '.' must be given as '\.

##### Meta-Characters
```shell
[a, b, z] #Means the following expressions for all the specified symbols
[0123456789] = [0-9]
#[A-Z] or [a-z] or [a-zA-Z] 
[abz] = a|b|z
[abz]* = (a|b|z)*

\< # Beginning of the word
\> # End of the word
$  # End of the line
^  # beginning of the line, inside a class means the negation
[^0-9] # means all characters which are not number

* #means [0, ∞] times 
+ #means [1, ∞] times 
? #means [0, 1] times 
[c1c2c3] #means Any character in parenthesis 
[c1-c5]  #means Any character in range 
[^c1-c5] #means Any character not in range 
{n} #means Exactly n times 
{n1,n2} #means n1 to n2 time

c # Any symbol c (excluding special ones) 
. # Any character (excluding ’\n’) 
\c # Any control character 
\s # A space or TAB 
\d # A digit [0-9] 
\D # Not a digit [^0-9] 
\w # Letters, numbers and _ [0-9A-Za-z_] 
\W # Not letters, numbers and _ [^0-9A-Za-z_]
```
Examples
```shell
ABCDEF # String "ABCDEF"
a*b # Any number of 'a' followed by a single 'b' 
ab? # a or ab 
a{5,15} # 5 to 15 repetitions of 'a' 
(fred){3,9} # 3 to 9 repetitions of string "fred" 
.+ # Any, non empty, sequence (entire line) 
myfunc.*(.*) # A function with name beginning by "myfunc" 
^ABC.* # A line beginning by "ABC" 
.*h$ # A line ending by "h" 
hello\> # Word ending by "hello" 
a+b+ # One or more 'a' followed by one or more 'b

.*b.*3 # Matches string "./fbar3" 
[a-zA-Z0-9] # A letter or a digit 
A|b # A or b 
\w{8} # A 8 character word 
((4\.[0-2])| (2\.[0-2])) # Numbers 4.0, 4.1, 4.2 or 2.0, 2.1, 2.2 
(.)\1 # Two times the same character (ex. "aa") 
(.)(.).\2\1 # Any 5 character palindrome string (radar, civic, 12321, etc.)
```

Write a RE to match 
- All the lines containing an integer number between 1 and 50 (extremes included)
```shell
^[1-9]$ | ^[1-4][0-9]$ | ^50$
```
- Any date with format yyyy/mm/dd 
	- A year can be expressed on 2, 3 or 4 digits. Assume that the number of days of each month is 31.
```shell
\d{2,4} \/ (0[1-9] | 1[0-2]) \/ (0[1-9] | [1-2][0-9] | 3[01])
```
#### Find
**Allows** 
- Searching and listing the file, directories or links that match a given criterion 
- Possibly executes a shell command on every listed file 
**Notice that** 
- Find outputs the relative path of the matching files, not their basenames 
- This is important to write the REs to match a give path and the actions to be performed

**Format** 
- find directory options actions 

In details, the find command 
- Visits the **directory subtree** 
- Outputs the list of pathnames satisfying the **options** 
- Possibly performs the **actions** on every file of the list 

>We need to analyze how to specify directory, options and actions.
>The command is recursive
###### Specify directory
```shell
find . # search this dir
find /usr/bin # search /usr/bin
```
###### Specify options

| Option                                              | Meaning                                                                                                                                                                                                             |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| -**type** type                                      | File type **f** per regular file (i.e., text files, executable, etc.), **d** for directories, **p** for pipes, **l** for symbolic links, **s** for sockets                                                          |
| -**name** pattern                                   | Match with the file name. The initial path (basename) is removed. In some versions it is possible to place the pattern between double quotes to specify regular expression. **-iname** is equal but case insensitiv |
| -**regex** expr                                     | Specifies a regular expression that matches the found relative path (full path) **-iregex** is equal but case insensitive                                                                                           |
| -**regextype** type                                 | Indicates the type of regular expressions used: posix-basic, posix-egrep, posix-extended, etc. You must specify the type before the regular expression (**regextype must precede regex**)                           |
| -atime \[+,-]n<br>\-ctime \[+,-]n<br>\-mtime\[+,-]n | Last access, status or modification time n=1 specifies from 0 to 24 hours back n value with sign : + means ≤, - means ≥                                                                                             |
| -size [+,-]n[bckwMG]                                | File dimension Sign + means ≥, - means ≤ Next character indicates the size : <br>- b blocks (of 512 bytes) <br>- c bytes <br>- k kbytes <br>- w word (2 bytes) <br>- M Mbytes <br>- G Gbytes                        |
| -user name<br>-group name                           | File owner identifier (user name) <br>File group identifier (group name)                                                                                                                                            |
| -readable <br>-writable <br>-executable             | File access permissions                                                                                                                                                                                             |
| -**mindepth** n <br>-**maxdepth** n                 | Search limited to a subtree section: **mindepth** and **maxdepth** indicate the minimum and maximum depth from **directory** (-maxdepth 1 means search only on directory)                                           |
###### Specify actions
| Option        | Meaning                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------ |
| -print        | Default action. Print a name for each lin                                                        |
| -print0       | Like -print, but without going in the next line                                                  |
| -delete       | Deletes the founded filename                                                                     |
| -exec command | Secure POSIX version of the previous one. Expands the command by including the path and the name |
The execution of a command is performed by means of the option exec:
	
	find directory options -exec command '{}' ';'
	find directory options -exec command \{} \;

The **command** is executed in the directory
- in which the pathname has been found by using execdir 
- in the current directory if exec has been used 
**find** substitutes string '{}' (or \\{}) with the current pathname of the list 
String ';' (or \\;) terminates the command executed by find.
