A possible classification is related to the application domain:

**General Purpose OS**:
- They can manage several different tasks, they try to maximize throughput
- Supercomputing, mainframe, server, workstation used for common tasks

**Specific Purpose OS**: 
- Real-Time (Safety critical, aerospace) Embedded systems (automotive)
  they can be divided into Soft Real-Time and Hard Real-Time. 
  Soft se non è in cose critiche, tipo streaming di video o altro
  Hard se viene usato in veicoli o per applicazioni per cui se c'è un blocco qualcuno si fa male
- Handlet device tipo arduino, smart card

>MacOS and LINUX use the UNIX standard, while windows has its own.

Different implementations of the UNIX operating system exist:
- AIX (IBM) 
- Digital Unix (Compaq) 
- HP-UX (Hewlett Packard) 
- IRIX (Silicon Graphics) 
- **MacOS X** (Apple) 
- FreeBSD (Free Software Foundation) 
- Solaris (Sun Microsystem) 
- **Android** (Android Inc. first, then Google from 2005) 
- **Linux** (Ubuntu, Fedora, Debian, etc.)

>Androind uses a modified version of the Linux Kernel, does not adopt the same application of the GNU libraries.
