In UNIX/Linux a **filter** is a command that
- Takes its input from standard input 
- Process (filters) it according to some parameters and options 
- Produces its output on standard output 
Commands that are useful tools for text file processing.

Most popular filters 
- awk, cat, cut, grep, head, python, sed, sort, tail, tr, uniq, w
```shell
cat example.txt | head -n 3 | tail -n 1
234 Bianchi Gianna 17.0

cat example.txt | head -n 3 | tail -n 1 | wc -W
4

#OTHERS
awk # analyze your file line by line and execute a program (not in course)
sed # search a regular expr and substitute it with a word (not in course)
cat # print the output of a program to the screen
cut #-> for columns
grep #-> for rows
sort # sort the result
```
#### Cut
Selects and outputs sections from each line of files 
Format 
- cut [options] file 
Main options 
- --characters=LIST, -c LIST 
   Select only the characters at the positions in LIST 
- --fields=LIST, -f LIST 
  Selects the (comma separated) list of fields 
   Format 
	   n (=n), -n (≤n), n- (≥n), n1-n2 (≥n1 && ≤n2) 
	   Examples: 3, -3, 3-, 3-5
```bash
cat example.txt
408 Rossi Giulia 30.0
12 Rossi Stefania 21.5
234 Bianchi Gianna 17.0
123 Bianchi Bianchi 30.0

cut -c 2 example.txt #Select the column 2
0
2
3
2

cut -c 2-4 example.txt #Select the column from 2 to 4
08 
2 R
34
23

#You can also use a range
cut -c 2-4,7-9 example.txt #Select the column from 2 to 4
cut -c 10- example.txt # select starting from 10

#there is d, which set the delimiter between columns
cut -d " " -f 2 example.txt # I select the column of the surnames
cut -d " " -f 3 example.txt # I select the column of the names
cut -d " " -f 4 example.txt # I select the column of the scores
cut -d " " -f 1-2,4 example.txt # all columns but names
```
Example:
Print how many characters are present in all files with extension ".txt" (without displaying additional information):
```shell
find . –name "*.txt" –exec wc \{} \; | cut –f 3 –d " "
```
#### Tr
Translate, compress, and/or delete characters from standard input, writing to standard output.
Must be used by redirecting the output of other commands to its input.
Format 
- tr [options] set1 [set2] 
Main options 
- --delete, -d 
   Delete the characters in set1 
- --squeeze-repeats, -s 
   replace each input sequence of a repeated character that is listed in set1 with a single occurrence of that character 
```shell
cat example.txt | tr i a # substitute the i with a
cat example.txt | tr ia ai # substitute the i with a and a with i

cat example.txt | tr a-z A-Z # upper case all the lower letters
# -d stands for delete
cat example.txt | tr -d a-z # deletes all the lowercase letters
# -s allows to remove repeated chars (mainly used for spaces)
cat example.txt | tr -s " " # deletes the useless spaces between columns
```
#### Sort
Sort the input file in alphabetic order.
Format 
- sort [options] [file] 
Main options 
- --ignore-leading-blanks, -b (non citato) 
   Ignore the initial spaces 
- --dictionary-order, -d (non citato)
   Considers spaces and alphabetic characters only 
- --ignore-case, -f (non citato)
   Transforms lowercase characters in uppercase characters (Case insensitive)
- --numeric-sort, -n 
   Sort in numeric order 
- --reverse, -r 
   Sort in reverse order 
- --key=c1,[,c2], -k c1[,c2] 
   Sort on the basis of the selected fields 

```shell
# sort alphabetically, (space is after numbers in ASCII) 
sort example.txt

# Perform a numerical sort in column number 1
sort -k1,1n example.txt

# Perform a numerical sort in column number 1, reversed
sort -k1,1nr example.txt
# if column 1 is equal apply a new rule (reverse alphabetical sort)
sort -k1,1nr -k2,2r example.txt
sort -k1,1nr -k2,3r example.txt # This apply from column 2 to 3

# -R, random sorting the elements (shuffle them)
sort -R example.txt
```
#### Uniq
Report or omit repeated lines of the input file 
Format 
- uniq [options] [inFile] [outFile] 
The file **must be sorted**. 
Without options eliminates the repeated lines.

Main options:
- --count, -c 
   prefix lines by the number of occurrences
- --repeated, -d 
   only print duplicate lines, one for each grou
- --ignore-case, -I
  Non case sensitive
```shell
#uniq use compare only near values, adjacent lines
sort example_uniq.txt | cut -d " " -f 1| uniq -c example_uniq.txt

# -d option tells which are the repeated valeus
sort example_uniq.txt | uniq -d -c example_uniq.txt

# -I treat ciao and CIAO as the same word
```

#### Grep
grep 
- Standard version
**egrep**, fgrep, rgrep
- egrep equivalent to ”grep –E” 
- Uses Extended RE for matching the pattern
Format
- grep [options] pattern [file]
Main options
- --regexp=PATTERN, -e PATTERN 
  Specifies the search patterns.
  Allows you to specify multiple patterns 
- --line-number, -n 
  Outputs the matching line number 
- --inverse-match, -v 
  Outputs only the lines that do not matc
- --ignore-case, -I 
  Case insensitive 
- --after-context=N, -A N 
  Outputs N lines after each match line (in addition to the line in which the match was found) 
- --before-context=N, -B N 
  Outputs N lines before each match line (in addition to the line in which the match was found) 
- --with-filename, -H 
  Outputs the filename for each matching line
```shell
#Search Rossi or rossi inside the file
egrep "(R|r)ossi" example.txt
egrep "[Rr]ossi" example.txt

# Also Gianna
egrep "[Rr]ossi|Gianna" example.txt

# -e options -> it's like an or, if any of the regular expression is matched
egrep -e "[Rr]ossi" -e "Gianna" example.txt

# match 25.5 to 30.5
egrep -e "25\.[5-9]|2[6-9]\.[0-9]|30\.[0-5]"  example.txt

# -A 2 means after, print also 2 lines after the matched result
# -B 2 means before, print also 2 lines before the matched result
egrep -A 2 -B 2"Gianna" example.txt

# -H allow you to see the file that contain the output if you use *.txt
egrep -H "Gianna" *.txt

# -n show also the line number of the matched line
egrep -n -H "Gianna" *.txt

#-V print only the lines not matched by the regular expressions
egrep -n -H -V "Gianna" *.txt #Doesn't print Gianna
```
