#### Commands

```shell
man ps # Show the description of the command

apropos printf # analizza e stampa tutte le versioni di printf nel manuale

whereis ls # ti dice in che dir si trova il comando (programma del comando)

whatis write # mostra le descrizioni di quello che fa il comando

which ls # Mostra la posizione dell'eseguibile (comando)
```

**Unix-like command syntax**
	command [options] [arguments]
The name of the command is associated to the action performed.
The options (optional, 0 or more) have conventionally two formats 
- The character '-' followed by only another character 
	- -ch1 -ch2 ... 
- The two characters "--" followed by a string 
	- --str1 --str2 ...
>Arguments are optional

##### Chmod
```shell
chmod #Allows to change the permission to a file
```
Alternatively by means of 
- a letter: u(ser), g(roup), o(ther), a(ll) 
- a symbol: +, -, = (add, subtract, untouched) - a character: r, w, x (read, write, execute)
```shell
chmod 777 document.txt # rwx rwx rwx
chmod 000 document.txt # --- --- ---
chmod +x document.txt  # --x --x --x
chmod u+w document.txt # -wx --x --x

chmod -R 755 /percorso/della/cartella # Ricorsiva
```

#### Hard Link
In Linux is possible to have more file pointing to the same area of memory/data segment (also in the same dir).
This is mainly use to non waste space, you don't have to copy the file but just the pointer at it, and the modify are visible to all the other reference link.

>If I remove the file and call the cat from another reference I am still able to see the file.
>To remove the file phisically you have to remove all the hard link and the file has not to be open also.

You can see the link counter with:
```shell
ls -li
```
