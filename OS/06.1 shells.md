At login (and exit) a shell looks for, and executes, some configuration files that contain initialization (or termination) commands 
**Startup files** differ in 
- **Login files** 
  Shell is executed after authentication in the system (password) 
- **Non-login** **files** 
   The shell is executed through an icon or system menu
##### Login with password
For each login with password, the shell executes 
- Global scripts 
	- /etc/profile 
	- User scripts (executes the first existing file among) 
		- ~/.bash_profile 
		- ~/.bash_login 
		- ~/.profile 
- There is an error in case of incorrect or unreadable file
##### Login without password
For each login without a password, the shell executes 
- ~/.bashrc 
- This file often refers to ~/.bashrc_profile 
- It is also the file typically executed in remote login 

For each logout, the shell executes 
- ~/.bash_logout
#### shell command expansion
Some characters have special meaning within the shell.
bash provide complex substitution mechanisms 
- After dividing the command line into tokens, the shell expands or solves these tokens, i.e., it applies different types of replacement 
	- Braces, tilde, variables and parameters, commands, arithmetic expressions, etc. 
- The substitution is complex and takes place with a specific order

Example:
```bash
ls *.txt

ls -l *.txt 

#It's expanded in
ls -l a.txt b.txt c.txt
```
#### Parentheses (), \[], {}
Enclose variables, arithmetic operations, etc. 
In some cases, they are subject to automatic expansion (brace expansion)
```bash
name=Jean 
echo $namePaul #This variable doesn't exist

echo {$name}Paul 
{Jean}Paul 

echo ${name}Paul 
JeanPaul
```
#### Quoting
"Quoting" means the use of for quotation marks 
- Quotes ' ' 
	- Variables within quotes **are not expanded** 
	- They cannot be nested 
- Double quotes " " 
	- Variables within double quotes **are expanded** 
	- They can be nested 
- Backslash \ 
	- Identifies the escape character, which remove the special meaning of the character that follows it

```bash
myVar="A string" 
echo $myVar 
A string 

echo 'v = $myVar' # No expansion
v = $myVar 

echo "v = $myVar" #Expansion
v = A string 

echo \$myVar 
$myVar 

echo "double quote\"" # \ cancels the meaning of the next character, which becomes a "meta-character"
double quote
```
#### Using the output of command
The standard output of a command can be captured by 
- Enclosing the command in $(...) 
- Enclosing the command in backquotes \`\` 
In particular, the output of a command can be stored in a variable
```bash
d=$(date) 
echo $d 
Fri Nov 22 10:00:0 \ CET 2013 

d=`date`
...

out=`cat file.txt` 
echo $out 
... file content ... 

out=`< file.txt` # Equal to cat
echo $out 
... file content ...
```
In a shell, a command can be executed 
- **Directly** 
	- cd /home ; ls 
- **Indirectly** 
	- (cd /home; ls) -> The current shell executes the command in a subprocess
Example
```bash
#ls <-> (ls)
(x="ste") 
echo $x
# nothing, since it opens a new shell and perform the command

x="ste" 
echo $x
#ste
```
#### Aliasing
In shell you can define new names to existing commands.
The **alias** command allows defining these names 
- alias name="string" which defines a new alias for "string" 

The shell maintains a **list of aliases** 
- alias, provides the list of active aliases used in the shell 

Old aliases can be deleted 
- unalias name , Deletes the alias name from the shell

```bash
alias ls5="ls -ltr | tail -n 5"
ls5 # runs the above command 
```
