The 'standard' shell commans
- Allow executing processes **sequentially** 
- Each process is executed in **foreground**, i.e., using the control terminal
#### Background execution
The shell interpret character & as an indication to run the command in **background** 
- The process is executed in concurrency with the shell. It loses the control terminal input 
- The shell outputs immediately a new prompt 
- It is possible to run several processes in parallel

>We can have only one process in Foreground and n>1 in background
>You can also place a background process in foreground using:
>- fg %2 -> process number 2 is set in foreground
##### Suspended
There is a state, named **suspended**: 
- ctrl+z suspend the process 
	- fg %1 resume it in foreground
	- bg %1 resume it in background
>A suspended process does not use the CPU.

>bg can be suspended using signals, (kill -SIGSTP).
