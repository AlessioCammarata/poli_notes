Examples
```shell
cat f1.txt | head -n 4 # This mean that I apply the command on the output of cat

# 12 ste
# 35 giu
# 45 ste
# 43 gab

cat f1.txt | head -n 4 | tail -n 3
# 35 giu
# 45 ste
# 43 gab

cat f1.txt | head -n 4 | tail -n 3 | wc -l
#3
```
>It allows to concatenate commands, like it's a stream.

Example:

```c
/*
 * Illustrates the use of shell (!!!) pipes
 *
 * To compile: gcc -Wall e01-pipeTry.c -o try-pipe
 * Examples:
   ls | ./try-pipe
   ./try-pipe < in.txt &> out.txt
   ./try-pipe < in.txt 1> out_stdout.txt 2> out_stderr.txt
 */

#include <stdio.h>
#include <stdlib.h>

int
main (
  )
{
  char buf[1024];

  while ( fgets(buf, 1024, stdin) != NULL ) {
    printf ("PIPE EXAMPLE:\n");
    fprintf(stdout, "%s", buf);
    fprintf(stderr, "%s", buf);
  }

  return (0);
}
```
